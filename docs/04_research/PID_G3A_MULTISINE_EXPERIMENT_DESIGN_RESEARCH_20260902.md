## 3. Full-harmonic orthogonal multisine for 2×2 G3-A

The earlier disjoint-line idea (`K_N ∩ K_E = ∅`) is acceptable for qualification, as demonstrated by Q3, but it is not preferred for the scientific 2×2 FRF campaign because the two FRF input columns would be directly excited on different frequency grids.

NASA's 2025 octocopter system-identification work presents **full-harmonic orthogonal multisine** excitation: multiple inputs may contain the same frequency content, while orthogonality is generated by repeating maneuvers with changing multisine polarities. This simplifies MIMO frequency-response estimation and was demonstrated on a small octocopter.

For two G3 inputs, use the 2×2 Hadamard polarity pattern

\[
H_2=\begin{bmatrix}1&1\\1&-1\end{bmatrix}.
\]

For one phase realization, run an orthogonal pair:

```text
Pair A: u_N = +m_N(t), u_E = +m_E(t)
Pair B: u_N = +m_N(t), u_E = -m_E(t)
```

Both N and E use the same scientific frequency grid. The pair is treated as one complete identification realization for split/accounting purposes.

The Q3 disjoint-line root remains valid mechanism evidence; it is not invalidated or rewritten.

## 4. Phase optimization and crest factor

NASA aircraft-identification practice uses orthogonal, phase-optimized multisines and Fourier-domain MIMO response estimation. Multisine phases are optimized to reduce relative peak factor so that useful spectral power can be injected while keeping the vehicle near the operating condition.

For G3-A:

```text
- use deterministic phase-optimized multisines;
- preserve the exact phase/seed identity prospectively;
- keep the same realization within each +/- orthogonal pair;
- change only the required polarity between pair members;
- never retune phase after inspecting vehicle response;
- enforce the already qualified global external-action norm cap <= 0.35 m/s² unless a later prospective contract lowers it.
```

Phase optimization is an input-design tool, not a license for adaptive same-campaign tuning.

## 5. Periodicity and record structure

Periodic multisine excitation is preferred because the excited frequencies can be exact Fourier bins and repeated periods permit direct repeatability/noise diagnostics without relying only on arbitrary Welch windows.

A practical initial design, to be frozen only after band qualification, is:

```text
base period T0 ≈ 8 s
fundamental Δf ≈ 0.125 Hz
5 periods/session
period 1 = entry/transient, excluded from scientific estimates
periods 2–5 = 4 admitted repeated periods
```

This gives approximately 40 s excitation per session and approximately 32 s admitted periodic data. This is an engineering recommendation consistent with the already qualified ~0.126 Hz low line and with standard multisine practice; it is not claimed as a universal theorem.

Every promoted scientific line must have multiple complete admitted cycles. The Q0–Q3 ~8 s records are mechanism-qualification evidence only and must not be reused as the G3-A scientific duration by default.

## 8. Signal-quality promotion: no magic coherence threshold

Do not use a universal fixed rule such as `coherence > 0.8` or `> 0.9` as the sole frequency-promotion gate. Coherence significance depends on the effective degrees of freedom/averaging structure, and a small cross-axis FRF may be physically real rather than a failed experiment.

The G3-A quality contract should combine:

```text
INPUT SUPPORT
- accepted spectral line is actually present;
- source-valid line occupancy;
- full input experiment matrix is rank 2;
- conditioning acceptable by a prospectively defined rule.

RESPONSE SUPPORT
- response at the line is distinguishable from zero-action/noise uncertainty;
- phase/magnitude estimate has finite uncertainty;
- no source/timing/authority invalidity.

REPEATABILITY
- repeated periods agree within estimated uncertainty;
- independent orthogonal phase-realization pairs agree within estimated uncertainty;
- held-out realization is reserved for model validation.
```

Coherence should be reported frequency-by-frequency with a significance/uncertainty interpretation derived from the actual period/realization structure, not a post-hoc desired number.

## 9. Accepted-action timing and irregular sampling

The scientific input remains `U_accepted_NE`, not requested or merely published action.

Reconstruct the input causally:

```text
U(t_y) = latest source-valid U_accepted whose accepted/read timestamp <= t_y
```

This is a causal accepted-action zero-order hold. Forbidden identification alignment includes nearest-neighbor assignment that can select a future action, host-wall-time alignment, or interpolation that anticipates a future accepted generation.

The G3 qualification roots show irregular accepted-action intervals and nonzero action-to-state delay/jitter. System-identification literature on irregular/random sampling shows that identifiability and persistent excitation depend jointly on input values and sampling times; therefore source timestamps must remain first-class evidence.

For the **primary frequency-response estimate**, prefer timestamp-native processing at the designed frequencies rather than resampling everything before spectral analysis:

- compute the accepted ZOH input Fourier coefficient from its true update intervals;
- estimate output harmonic coefficients directly at the irregular `VehicleLocalPosition.timestamp_sample` times by sinusoidal/harmonic least squares (or an equivalent nonuniform Fourier estimator);
- retain exact phase/delay provenance.

Uniform resampling should be deferred to later VARX/PBSID preparation, after the useful FRF band is known and an explicit causal interpolation/anti-alias policy can be frozen.
